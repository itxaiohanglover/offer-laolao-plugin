## 安装方法

本插件提供三种安装方式，推荐使用Edge插件商店安装，对于开发者可选择开发者模式加载。

### Edge插件商店安装（推荐）

1. 访问 **[Microsoft Edge 插件商店](https://microsoftedge.microsoft.com/addons/detail/bhebbhnjfageofcfejjbgneclnmakpgp)**
2. 点击页面上的 **"获取"** 按钮进行安装
3. 安装完成后，浏览器工具栏上会出现插件图标
4. 点击图标即可打开简历填写助手

### 开发者模式加载

如果您希望从源码构建并加载插件，请按以下步骤操作：

1. **下载项目源码**
   ```bash
   git clone https://github.com/itxaiohanglover/offer-laolao-plugin.git
   cd offer-laolao-plugin
   ```
   或者直接下载ZIP文件并解压。

2. **安装依赖并构建**
   ```bash
   # 安装 pnpm（如果尚未安装）
   npm install -g pnpm
   
   # 安装项目依赖
   pnpm install
   
   # 构建插件
   pnpm build
   ```
   构建成功后，会在项目根目录生成 `build/chrome-mv3-prod` 文件夹。

3. **在浏览器中加载扩展**
   - 打开 **Chrome** 或 **Edge** 浏览器
   - 在地址栏输入 `chrome://extensions/` (Chrome) 或 `edge://extensions/` (Edge)
   - 打开右上角的 **"开发者模式"**
   - 点击 **"加载已解压的扩展程序"**
   - 选择项目中的 `build/chrome-mv3-prod` 文件夹
   - 加载成功后，插件图标将出现在浏览器工具栏

## 首次启动与界面导航

首次启动插件后，您将看到一个清晰的用户界面，主要分为两个功能区域：**简历填写** 和 **设置**。

### 界面概览

插件主界面是一个宽度为400px的弹窗，顶部为带有品牌标识的蓝色渐变标题栏。下方通过标签页（Tabs）组织功能。

- **📝 简历填写**：核心功能区，用于管理简历数据
- **⚙️ 设置**：配置AI模型、解析服务和界面偏好

### 简历填写标签页

此标签页是您管理简历信息的主要工作区，包含以下组件：

1. **模板选择器**：位于顶部，支持创建、切换、重命名、复制和删除多个简历模板。
2. **上传简历区域**：支持拖拽或点击上传PDF、DOCX、JSON等格式的简历文件。
3. **简历表单**：包含个人信息、求职期望、教育经历、工作经历、项目经历、技能、语言能力等所有模块的输入表单。
4. **导出按钮**：位于底部，用于导出简历数据。

### 设置标签页

此标签页允许您配置插件的高级功能：

1. **界面设置**：选择 **弹窗模式** 或 **悬浮窗模式**。
2. **AI模型配置**：配置用于简历内容优化的AI大模型服务。
3. **简历解析配置**：配置用于解析PDF/Word简历的API服务。

## 基础操作演示

### 上传简历

您可以将现有的简历文件上传并解析到插件中。

1. 在 **"📝 简历填写"** 标签页，找到 **"上传简历"** 区域。
2. **拖拽** 您的简历文件（PDF、DOCX、JSON等）到虚线框内，或点击该区域选择文件。
3. 如果是PDF或Word文件，插件会调用您配置的 **简历解析API** 进行解析；如果是JSON文件，则直接导入。
4. 解析完成后，点击 **"✓ 使用解析数据"** 按钮，数据将自动填充到表单中。

### 切换模板

插件支持管理多个简历模板，方便您为不同职位定制简历。

1. 在 **"📝 简历填写"** 标签页顶部，找到模板选择器的下拉菜单。
2. 选择您想要使用的模板，表单内容会立即切换。
3. 点击 **"+"** 按钮创建一个全新的空白模板。
4. 点击 **"✏️"** 按钮修改当前模板的名称。
5. 点击 **"📋"** 按钮复制当前模板，创建一个副本。
6. 点击 **"🗑️"** 按钮删除当前模板（至少保留一个模板）。

### 手动填写

您也可以直接在表单中手动填写简历信息。

1. 在 **"📝 简历填写"** 标签页，直接在各个输入框中填写您的个人信息。
2. 对于教育经历、工作经历等可重复的模块，点击 **"添加"** 按钮来增加新的条目。

4. 填写完成后，您可以随时通过 **"导出"** 功能备份数据。

## AI模型与解析服务配置

### 配置AI模型API Key

要使用AI简历优化功能，您需要配置一个AI大模型服务的API Key。

1. 点击插件图标，切换到 **"⚙️ 设置"** 标签页。
2. 在 **"AI模型配置"** 区域，从下拉菜单中选择一个服务提供商（如DeepSeek、Kimi、通义千问等）。
3. 选择您要使用的具体模型。
4. 在 **"API Key"** 输入框中，输入您从对应平台获取的密钥。
5. 点击 **"🔗 测试连接"** 按钮，验证配置是否正确。

### 配置简历解析服务

要解析PDF或Word格式的简历，您需要配置简历解析API。

1. 在 **"⚙️ 设置"** 标签页，找到 **"简历解析API配置"** 区域。
2. 在 **"API URL"** 输入框中，输入您购买的简历解析服务的API地址。
3. 在 **"APP Code"** 输入框中，输入您购买服务后获得的APP Code。
4. 保存配置后，即可上传并解析PDF/DOCX格式的简历。

## 完整简历填充流程

完成配置后，您可以开始使用插件自动填充招聘网站的简历表单。

### 步骤一：准备简历数据

1. 通过 **上传简历** 或 **手动填写** 的方式，在插件中准备好您的完整简历信息。
2. （可选）配置好AI模型后，点击 **"✨ AI一键简历优化"** 按钮，让AI智能优化您的自我介绍、工作描述等内容。

### 步骤二：在招聘网站上填充

1. 打开目标招聘网站（如智联招聘、前程无忧、BOSS直聘等）的简历填写页面。
2. 点击浏览器工具栏上的插件图标，打开插件弹窗。
3. **字段级精确填充（推荐）**：
   - 在插件表单中，找到您想要填充的字段（如"姓名"）。
   - 点击该字段旁边的 **"↗"** 按钮，进入"点选填充"模式。
   - 此时插件弹窗会自动关闭，页面上可填充的输入框会显示蓝色高亮边框。
   - 点击网页上对应的目标输入框，该字段的值就会被精确填充。
   - 按 `Esc` 键可取消操作。
4. **一键预填（即将上线）**：
   - 点击插件中的 **"📋 预填"** 按钮。
   - 插件会自动识别页面上的表单字段，并尝试智能匹配和填充所有内容。

## 常见问题与提示

### 权限配置

插件需要以下浏览器权限才能正常工作：
- `activeTab`: 访问当前活动标签页
- `scripting`: 向网页注入脚本以实现填充功能
- `storage`: 在浏览器本地存储您的简历数据

这些权限已在 `package.json` 的 `manifest` 字段中声明，安装时会自动请求。

**Section sources**
- [package.json](file://package.json#L50-L54)

### 网站兼容性

- **通用兼容性**：插件使用通用表单识别技术，理论上支持所有招聘网站。
- **特殊组件**：少数网站可能使用了特殊的表单组件，如果自动识别失败，建议使用 **字段级精确填充** 功能手动指定填充位置。
- **不支持的页面**：系统页面（如 `chrome://`, `edge://`, `about:`）不支持内容脚本注入，因此无法使用。

**Section sources**
- [README.md](file://README.md#L274-L288)

### 数据安全

- **本地存储**：所有简历数据仅存储在您的浏览器本地，不会上传到任何服务器。
- **隐私保护**：插件不会收集或发送您的任何个人信息。
